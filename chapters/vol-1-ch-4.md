# 第4章：河道

- **卷号：** 1
- **章节：** 4
- **状态：** drafted

## 大纲

**概要：** 觉醒后第一个修炼日。林夜在基础修炼场首次运转《引雷术》，完成第一个小周天——灵气转化效率比同级高，初始境界停在感气后期。王虎在体修区完成首次气血淬炼，淬皮中期。修炼场的早晨，每个人的路开始分岔。指导教师在场边巡视，在灵气输出监测屏上看到一个偏差值偏小的数据点。

**关键点：**

1. [推进剧情·环境] 清晨六点半，基础修炼场。场子很大，地上画着方格——灵修区在左边，体修区在右边，中间隔着一条走道。空气里有残留的灵气波动，是早到的那批人留下的。林夜到的时候场上已经有一些人了，有的盘腿坐着，有的在调息。王虎已经在了——他在体修区跟一个三百斤的石锁较劲。

2. [推进剧情] 林夜找了块空地坐下来。识海里《引雷术》的经脉地图还在——不是记忆，是直接印在脑子里的画面。他闭上眼，丹田里的那团雷属性灵气开始沿着功法给的路线走。第一次运转不顺利——灵气在经脉分岔口堵了一下，他没硬推，退回去重新来。第二次顺了。第三次已经不需要刻意引导。不是比别人快，是每一步都踩在正确的位置上。灵气像水找到了河道——不是他造了河道，是河道本来就在那，只是之前没有水。

3. [推进剧情·平行] 王虎那边完全是另一种画风。体修的第一次淬炼需要把无属性灵气转化为气血，然后推动气血淬炼皮肤——不是坐着调息，是一边扛着石锁做深蹲一边运转气血。王虎的呼吸很重但稳得住——淬皮中期对应的气血强度在他这个体格上体现得直接。满脸通红，汗在额头上，但动作没变形。旁边有个同是体修的男生扛了一半把石锁放下了，撑着膝盖喘气。王虎还在蹲。不是天赋碾压——是B级体赋配三百斤石锁，刚好在他的能力范围内。他能感觉到气血往皮肤表层渗的时候在发烫，像整个人包了一层薄薄的热水袋。指导教师在场边喊了句"第一次淬炼不要超过一小时，皮会裂"。王虎应了一声，又蹲了五个才把石锁放下。

4. [推进剧情·爽点伏笔] 林夜第一个小周天走完。灵气从丹田出发，沿经脉走了一圈回到丹田——然后丹田里的雷属性灵气跳了一下。不是炸，是"到站了"的那种确认。九年积累的无属性灵气在这一刻开始正式转化——不是一次性全部转化，是开了个口子，后面的会随着修炼逐渐释放。他现在的境界停在感气后期。旁边不远有个同时开始的同级生也完成了第一个周天——那人睁开眼的时候明显在算自己的境界，算完表情有点复杂，大概是感气前期。林夜没去问。指导教师在场边看着灵气监测屏——屏幕上每人的数据在跳动。她低头在记录本上写了几个字。不是惊天发现——就是注意到一个数据点：偏差值比同级平均小了快三分之一。她抬起头往场上扫了一眼。场上几十个学生，她没特意找谁。合上本子，继续巡视。

5. [收束·对话] 上午训练结束。修炼场外面，王虎的胳膊红了一片——第一次淬皮留下的痕迹，不疼但皮肤发烫。林夜说"你像煮熟的虾"。王虎说"你是嫉妒，你坐一早上就完成了个小周天，我蹲了一早上"。两个人靠着场边的栏杆休息。周围还有学生在讨论各自的境界——感气前期、淬皮前期的最多，中期的次之，感气圆满的声音最少。林夜没特意去算自己的位置。感气后期，够了。够启动下一步。

6. [收束·结尾] 王虎约下午继续——上午是淬皮，下午还要接着淬第二轮。林夜说下午来——灵修的频率不像体修那么密，但也不能断。两个人往食堂走。王虎在念叨午饭该加几个菜——体修老师说淬皮期每天得多摄入两成热量。林夜说"你找了个合法多吃的理由"。王虎说"这是科学"。上午的太阳已经升起来了，修炼场上还有人在练——明天人会更多，后天也是。这条路开始了。

**出场角色：** 林夜、王虎、指导教师（韩素，不点名）、修炼场学生群
**场景地点：** 基础修炼场（灵修区+体修区）→修炼场外栏杆→往食堂路上
**时间：** 觉醒日次日上午
**叙事视角：** 第三人称有限视角（林夜）
**字数目标：** 2000-2500字（不低于2000字）

## 章纲内容

### 当前任务
修炼第一天——首次运转功法、完成灵气转化、确定初始境界。通过林夜和王虎两条平行线展现灵修和体修的修炼方式差异，同时用林夜第一个周天的细节暗示掌控力优势。

### 读者期待
- **情绪状态：** 功法到手，迫不及待想看实际修炼
- **策略：** 平行推进+细节埋线
- **具体说明：** 读者已经知道林夜的天赋和功法，现在想看这些怎么转化为实际能力。修炼画面本身是新信息——灵修怎么练、体修怎么练

### 兑现计划
- **必须了结：** 初始境界确定——林夜感气后期，王虎淬皮中期
- **必须压住：** 掌控力优势不宣之于口——只写过程，不写结论。"偏差值偏小"是数据层面的暗示，不用旁白翻译成"他比别人厉害"
- **推进不收束：**
  - 偏差值小三分之一——指导教师注意到了但没深究
  - 灵气转化效率比同级高——这个差距在后续修炼中会越来越大
  - 修炼的日常节奏开始建立——每天来修炼场，灵修体修各练各的

### 过渡功能
- 「吸收晶石→首次运转」→ 从知道功法到使用功法
- 「觉醒日→修炼日」→ 从"等待结果"到"开始行动"，节奏从低到中间稳态

### 关键抉择
- 初始境界感气后期——中上水平。不是天才级别（感气圆满），也不是普通水平（感气前期/中期）。配合A级属性，起点扎实但不炸场
- 首次运转的细节重点：不写"林夜的掌控力很强"，写"灵气到分岔口堵了一下→退回去重来→第二次顺了"——用动作过程暗示精准和耐心
- 指导教师注意到了数据偏差值偏小——不写成"发现了一个天才"，写成"注意到了一个数据点，多看了一眼场上，合上本子继续巡视"

### 角色信息状态
- 林夜：初始境界感气后期 / 知道自己的灵气运转比别人顺畅 / 不知道被注意到了
- 王虎：初始境界淬皮中期 / 胳膊红了 / 被叫煮熟虾 / 在算中午加几个菜
- 指导教师（韩素）：注意到了偏差值偏小的数据点 / 没深究 / 合上本子继续工作
- 陆辰：不出场。不在同一个修炼时段，或者在修炼场另一侧但林夜没注意

**对话：** 关键点5是本章主要对话，关键点2/3以叙述为主

### 章尾改变
- 信息改变：初始境界确定，修炼方式展现
- 节奏建立：修炼场→食堂→修炼场——修炼日常的循环感开始
- 伏笔埋下：偏差值的数据——指导教师什么时候会再注意到？
- 情绪出口：日常。太阳升起来了，路上还有人在练。这条路开始了。

### 硬约束
- 不写陆辰出场——修炼场可能有几百人，林夜不特意注意他
- 不写"掌控力""天资过人"等分析句——只用动作和数据暗示
- 王虎的体修修炼不写成"受苦"——他是累但不苦，体修就是这样
- 灵气转化效率的原理不通过旁白解释——读者从林夜和王虎的修炼细节中自然感受到差异
- 指导教师不写成"发现天才"的俗套——看了一眼，写了笔记，合上本子。就这样
