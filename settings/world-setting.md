# 世界设定

## 地理

### 人类领土

人类政权统一，以"市"为基本行政单位，按一二三线分级。

- **一线市**：边境军事重镇或内陆核心枢纽，拥有完整的修炼教育体系、灵石矿脉和军事力量。人类最强者多集中于此。
- **二线市**：中等城市，数量最多。有标准的九年修炼教育体系，但高阶修士密度远低于一线市。青江市即属此类。
- **三线市**：小型城市或农业区域，灵气浓度偏低，大多无独立修炼学院，依赖上级城市调配资源。
- **城市间交通**：灵气高铁连接各主要城市，普通人亦可乘坐。跨市通行需登记，一线市出入有额外审查。

### 妖兽领土

妖兽同样拥有统一政权，组织结构与人类类似。双方领土以边境缓冲区为界。

- 妖兽并非"野兽"——有组织、有纪律、有等级。高层同样有顶尖战力，与人类最强者数量大致对等。
- 妖兽领土覆盖人类领土以外的广阔区域，面积远大于人类领土，但开发程度低，资源分布不均。

### 边境与缓冲区

- 双方领土之间设有**缓冲区**，宽度约五十公里。任何一方成建制军事力量进入缓冲区视为开战信号。
- 缓冲区允许非武装人员活动，双方情报渗透从未停止。
- 双方各有三处**官方口岸**，定期交换情报、协商摩擦事件。口岸不开放民间贸易。
- **黑市**在缓冲区暗中繁荣——人类的矿石、丹药换妖兽的灵草、兽骨。两边政府心知肚明，睁一只眼闭一只眼。
- 每年约十几次小规模冲突，多发生在缓冲区，烈度被双方控制在不影响协议续存的范围内。

### 青江市

主角所在城市——内陆二线市，修炼教育资源中等偏下，无特殊产业支柱，典型的"够用但不出彩"的中型城市。人口约五百万。

- **第九修炼中学**：林夜和王虎的初中，占地三百亩，包含教学楼、修炼场、觉醒馆、体修训练中心。设施齐全但不算先进。学生升高中时按觉醒成绩和志愿分流至各高中。
- **青江市第一修炼中学（市一中）**：全市最好的公立高中。师资强、修炼场先进、市级功法库直接挂钩。学生以A/B级为主，世家子弟比例高于其他学校。林夜和王虎高中就读于此。
- **灵气枢纽**：城市灵脉交汇点，设有市级灵气调节站。学生觉醒仪式在此进行。

周边城市待故事主线确定后补充。

## 政治

### 统治形式

统一的人类政权，中央集权，架构类似现代科层制。修炼事务完全融入常规行政管理——不存在独立的"修炼者权力机构"。全民修炼意味着修炼管理就是常规行政。

- **中央**：统管全国修炼教育标准、灵石矿脉分配、军方调动、觉醒检测数据联网。
- **市级**：各市设修炼管理局，与市政府其他部门平级，负责本地灵气监测、觉醒仪式组织、学校管理、基础执法。
- **军方**：由修炼者组成的正规军队，是执法体系的最强保障。高阶修士犯法，由军方出动更高阶的修炼者执行镇压。

### 社会分层

- **修炼世家**：家族有化域及以上修士坐镇，跨代积累。核心优势不在功法（基础功法统一分配），而在私教指导、资源渠道、人脉网络和经验积累。世家之间联姻频繁，形成利益网络。
- **普通家庭**：无化域以上修士。孩子靠公立教育体系出头。觉醒前与世家子弟差距不大（公立灵气教室人人可用），觉醒后差距体现在课外指导、额外资源、社会关系等方面。
- **灵修与体修完全平等**：法律和社会认知均无歧视。两者战斗均势，优劣取决于个人操作和天赋，而非路线本身。

### 主要矛盾

- 世家希望维持"软性垄断"（私教、渠道、人脉），政府推行"修炼平民化"让每个人都有机会。两边互相需要也互相牵制。
- 边境一线市和内陆市在资源分配上存在结构性差距。
- 人类与妖兽之间的长期对峙是整个世界的底色。

### 法治体系

- 法律面前人人平等——至少制度上是这样设计的。
- 纪律手段：警告、罚款、扣押资源、封印修为、开除公职、监禁。
- 最高处罚：剥夺修炼资质——终生不得再修炼。需经过完整审判程序。
- 军方是执法体系的终极保障——再强的个体修士也扛不住成建制的修炼者军队。

## 规则

### 世界级：灵气体系

灵气分为**无属性灵气**与**属性灵气**。无属性灵气是基础，占空气中灵气总量的绝大多数。属性灵气由各亲和属性均分。

**天赋属性：**

| 级别 | 属性 | 出现概率 |
|------|------|----------|
| 常见 | 火、水、土、风 | 大部分觉醒者 |
| 少见 | 雷、冰、木、金 | 约两到三成 |
| 稀有 | 光、暗 | 极少出现 |
| 特殊 | 空间、时间等 | 理论存在，几乎无人见过 |

属性之间不存在严格的克制关系——优势取决于个人对属性的运用和操作，而非属性本身。

**天赋等级（属性天赋与体赋天赋各自独立评定）：**

| 等级 | 含义 | 出现比例 | 300人学校估算 |
|------|------|----------|-------------|
| F | 最低，勉强满足觉醒条件 | 8-12% | 25-35人 |
| E | 下等 | 10-15% | 30-45人 |
| D | 中下 | 30-35% | 90-105人 |
| C | 中等 | 22-27% | 65-80人 |
| B | 中上 | 10-14% | 30-42人 |
| A | 上等 | 1-2% | 3-6人 |
| S | 顶级 | 每年全国约15人 | 全国年均个位数，二线城市不出 |

大部分天才集中在A级，S级仅最顶尖的极少数人能达到，整个人类势力范围内确有但屈指可数。二线城市普通学校的主体分布在D等。

**觉醒前（义务教育阶段）：** 所有学生同时修炼两条路——练气（无属性灵气的基础吸收和经脉感知）和炼体（肉身基础淬炼）。不分家，两条路打底。无属性灵气积累为"灵气储备"。

**觉醒后：** 觉醒仪式检测天赋属性类型和体赋等级。根据天赋选择路线——灵修/体修/双修。觉醒前积累的灵气储备在觉醒后一次性释放，决定初始境界。

**修炼双轨：**

| | 灵修 | 体修 |
|------|------|------|
| **原料** | 无属性灵气 | 无属性灵气 |
| **转化方向** | 转化为天赋属性灵气（经脉修炼） | 转化为气血淬炼肉身 |
| **天赋决定** | 亲和属性类型和转化效率 | 无属性灵气转气血的效率 |
| **战斗方式** | 属性法术、中远程攻击 | 肉身强度、近战为主 |
| **优势** | 法术多样性、范围攻击 | 不依赖经脉、对灵气属性无要求 |
| **劣势** | 经脉受损风险、对属性灵气依赖 | 无法释放远程法术 |

**双修**：天赋条件允许，两者天赋接近可同时修炼。但消耗双份资源，修炼速度未必翻倍——极少有人选择。

**觉醒机制**：人类十五岁（初三毕业）时进行觉醒仪式。

- **检测内容**：判断修炼路线（灵修/体修）+ 评定天赋等级（属性/体赋）。
- **觉醒前**：两条路同时练——练气打底+炼体打底，不分家。无属性灵气积累为"灵气储备"。
- **觉醒后**：觉醒仪式确定天赋属性和体赋等级，分配基础功法。学生修习基础功法，将九年积累的无属性灵气转化为属性灵气（灵修）或气血（体修），首次转化完成时确定初始境界。转化时机因人而异——功法掌握越快、灵气掌控越精准，释放越早。通常数天至数周内完成。
- **每人一生仅一次**——错过或未通过则永远无法成为修炼者（极少数后天奇遇例外）。检测后分配的功法是修炼的起点，练成后才能完成第一次灵气转化、确定初始境界。

### 境界体系

灵修与体修各有五阶，每阶分五段：前期→中期→后期→圆满→极限。

| 阶 | 灵修 | 体修 | 对应阶段 |
|----|------|------|----------|
| 1 | 感气 | 淬皮 | 觉醒后初始 |
| 2 | 凝脉 | 锻骨 | 高中 |
| 3 | 御灵 | 通窍 | 大学 |
| 4 | 化域 | 换血 | 毕业后 |
| 5 | 归元 | 不灭 | 顶尖 |

### 社会级：义务修炼教育

- **九年义务修炼教育**：小学六年+初中三年，由国家免费提供基础功法和灵气教室。
- **觉醒检测公正性**：检测设备由国家统一制造、统一分发、统一管控——相当于高考试卷，在觉醒仪式当天由市级修炼管理局启用，仪式结束后回收。任何家族（包括世家）均无法提前接触设备或在非仪式时间使用。检测数据全国联网，不可篡改。这是觉醒仪式对所有人公平的制度基础：不是世家不想提前测，是根本测不了。
- **资源分配**：义务修炼教育阶段——每季度从国家灵石矿脉配额中按学生人头均分。灵修和体修配额价值完全相同。
- **初中毕业后**：补贴递减。想多修炼需自己想办法——奖学金、竞赛奖金、边境服役换军功资源，或家族支持。
- **大学前不接触妖兽**：只能通过教材和课程了解妖兽相关知识。真正面对妖兽是大学或服役之后的事。

### 个人级：功法获取

- 初期待觉醒——觉醒前无法确定修炼路线，能力局限于九年基础教育积累的水平。
- 核心优势——灵气掌控力天生精准。但这种优势是渐进式的，前期不会突然爆发。
- 资源受限于普通家庭背景——义务教育配额够用，但额外资源需要自己争取。

### 功法传承机制

功法存储在特殊晶石中，每枚晶石仅供一人使用。使用者以神识激活晶石后，功法内容直接印入识海——无需阅读背诵，瞬间获得完整的修炼知识和体感记忆。晶石使用后化为粉末，不可复用。

**功法不可外化**：印入识海的功法知识无法通过任何方式转写、绘制或口述给他人。你可以运转灵气、施展术法，但无法把"怎么运转"写在纸上——识海里的功法是一种体感记忆，不是文字信息。这也是为什么功法只能通过晶石传承：晶石是唯一能把体感记忆从一个修炼者复制到另一个的媒介。如果有人在地上画经脉图，画出来的只是一条线——没有灵气流速、没有力度控制、没有体感，看一百遍也学不会。

**功法晶石的制作**：只有将某部功法修炼至最高境界的人，才能将自身对该功法的完整理解注入空白晶石，形成新的功法晶石。制作者注入一次功法会消耗大量灵力和神识，短期内无法连续制作。功法等级越高、内容越复杂，制作成本越大。

**关于功法的几个规则：**

- **基础功法可以一直修炼**：觉醒时分配的功法并非"用完就废"——它是所属属性最底层的经脉运转框架，从感气期到归元期都能用。只是到了某个修为瓶颈后，基础功法提供的经脉路线太短，灵气转化效率跟不上境界需求，需要用更高级的功法来突破。功法本身不过期，是修炼者长到它不够用了。
- **换功法不卡熟练度**：想换更好的功法，唯一的前提是你搞得到更好的晶石。功法的熟练度只是你掌握程度的标签，没有任何解锁功能。熟练度满了不代表自动获得下一本。能不能换，看的是你竞赛拿了第几名、考核排到第几档、家里有没有长辈愿意给你做晶石、省吃俭用能不能攒够灵石去买。
- **功法熟练度**（独立于境界，仅表示对当前功法的发挥程度）：

| 等级 | 发挥了功法上限的 |
|------|-----------------|
| 入门 | 约三成——刚能走完路线，灵气常有卡顿 |
| 小成 | 约五成——运转流畅，效率达到基准 |
| 大成 | 约七成——经脉贯通稳定，略有溢出 |
| 圆满 | 约九成——接近零损耗，可微调细节 |
| 化境 | 十成——完全内化，脱离原有框架自行变通。达到此级才能制作该功法的晶石 |

- 熟练度只代表你把这本功法用到了什么程度，不影响你能不能换下一本。入门也能换，化境也能换——前提是你搞得到更好的晶石。

### 功法获取途径

基础功法由学校按属性统一分配晶石，均为义务教育标准功法（最低等级）。进阶功法可通过以下途径获取：

| 途径 | 说明 |
|------|------|
| **学期考核排名** | 排名靠前者可申请市级功法库的进阶功法 |
| **竞赛奖励** | 各级赛事获奖可兑换对应等级的功法 |
| **灵石购买** | 功法可在合法市场交易，价格取决于等级和稀有度 |
| **家族传承** | 修炼世家有代代相传的功法，不对外流通 |
| **私人交易** | 学生之间可私下转让或交换功法，价格自行协商 |

天赋和功法共同决定灵气转化效率——天赋决定亲和度上限，功法决定经脉路线的覆盖范围。二者叠加，缺一不可。

### 修炼资源

| 资源 | 作用 | 获取方式 |
|------|------|----------|
| **标准灵石** | 直接提供无属性灵气，灵修体修通用 | 政府按月配额（义务教育免费），超额自购 |
| **属性灵石** | 含特定属性灵气，灵修吸收效率更高；体修需额外转化 | 市场流通，价格高于标准灵石 |
| **气血丹/聚灵丹** | 体修用气血丹加速淬炼，灵修用聚灵丹辅助突破 | 公立配额+市场购买 |
| **修炼室** | 高浓度灵气空间，按小时使用 | 学校免费时段有限，超额付费 |
